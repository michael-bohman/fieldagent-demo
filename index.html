Embedding in GitBook

Through the fieldagent-demo GitBook integration the block is written in Markdown as a fenced code block, so it survives Git Sync:

```fieldagent-demo scenario="map-layers"
```

Without the integration, link out from the page instead: <a href="…/demo.html?s=map-layers&mode=page" class="button primary">Try it in the interactive demo</a>
